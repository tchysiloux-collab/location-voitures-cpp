# Location de voitures (C++)

Application console en C++ pour gérer la location de véhicules.

## Fonctionnalités
- Ajout de voitures
- Affichage de la liste des voitures
- Location d'une voiture et calcul du prix
- Sauvegarde des données dans un fichier
- Gestion des erreurs de saisie

## Compilation et lancement
1. Ouvrir `main.cpp` dans Code::Blocks (File > Open).
2. Compiler et lancer avec *Build and run* (F9).

Ou avec g++ dans le terminal :
g++ main.cpp -o location
